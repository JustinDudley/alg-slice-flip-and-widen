
README -- input alg library


On my local machine, the folder "library_of_input_algs" contains TWO FOLDERS:
   - one is small.
   - one is huge.


The small one is tracked by git.  It contains 72 files. 
Each file contains just the first 50 algs of a longer list.

The huge folder is untracked, and does not appear in github.
It has the same 72 files, but containing ~400,000 StickerSolve algs all told.
These are the input algs I used in this python project.
